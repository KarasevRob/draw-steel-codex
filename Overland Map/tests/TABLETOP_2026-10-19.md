## Live compatibility and deployment

All 12 changed runtime files were deployed together with `deploy.ps1`. SHA-256 comparisons
confirm that the development-folder copies match the repository. Overland was refreshed
and reloaded; its new preference and rail entrypoints and host methods were observed
live. The loaded host's `Raise` and `AtlasDragging` definition lines match the final source.
The bridge reports all mods loaded and no pending file changes. These checks establish
the deployed files and new runtime behavior; the API does not expose a full loaded-source
hash.

The connected build does not initialize `Tabletop` or `WindowSwitcher`, and its panel API
does not support `raiseOnPress`. The new assignment is therefore gated with the shared
Tabletop capability. The shared HUD CodeMod is not checked out: its two changed files
are staged in the development folder but cannot be claimed as running in this session.

Passed on this older build:

- Ordinary window and fullscreen views remain usable; the new placement/minimize
  controls are hidden. The map and Atlas were inspected visually at Font Size 100.
- Fullscreen hides the action bar and returning to window view restores it.
- Explicit Atlas selection survives generic host destruction, restoring without focus.
- Reload with a minimized preference produces a visible fallback host, leaves the
  preference minimized and does not focus it.
- Native Pop out records `native`; Return to app records `open`, removes the native
  owner and creates the in-app host.
- Explicit close records `closed`, and the window remains closed after refresh/reload.
- No Overland Lua errors or lifecycle-reconciliation errors were observed in the checked
  console intervals.

The live checks changed only personal UI preferences and host state. Original preferences,
Font Size, action-bar setting and code-monitor selection were restored, and temporary
in-app/native hosts were closed. No map rows, sharing settings or module publication
were changed.

Tabletop mouse/keyboard input, live MRU switching, docking, player roles, Font Size
80/100/140%, full application restart and tactical/PDF regression acceptance still need
a compatible build. Their offline coverage is recorded separately and is not a live pass.
